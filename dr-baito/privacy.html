プライバシーポリシー

合同会社鈴木医工（以下「当社」）は、「医師バイトBot」（以下「本サービス」）における利用者の情報を、以下のとおり取り扱います。

制定日：2026年10月16日（同日改定：予定の追加に関する記載を追加）

1. 取得する情報

  1. Googleアカウントの情報：連携したGoogleアカウントのメールアドレス
  2. Googleカレンダーの情報：予定の日時、終日予定かどうか、予定の状態（予定あり／空き）。予定の件名・場所などは、空き時間の判定に必要な範囲でのみ読み取ります。
  3. LINEの情報：LINEのユーザーID（お知らせの送り先として）
  4. 利用者が設定した条件：希望の報酬・場所・業務内容・曜日や時間帯など
  5. 利用の記録：お知らせの送信日時、求人ページを開いた記録など

2. 利用目的

  1. カレンダーから空き時間を判定し、条件に合う求人をお知らせするため
  2. 利用者が依頼した勤務の予定を、利用者の確認のうえでカレンダーに追加するため
  3. 利用者が言葉で書いた希望を、検索の条件に変換するため
  4. お問い合わせへの対応、不具合の調査、サービスの改善のため

上記以外の目的には使いません。

3. Googleのユーザーデータの取り扱い

  • 本サービスが求める権限は、Googleカレンダーの読み取り（https://www.googleapis.com/auth/calendar.readonly）と予定の追加（https://www.googleapis.com/auth/calendar.events）です。
  • 予定の追加は、利用者が本サービス上で内容（日時・件名など）を確認し、「追加する」を選んだときだけ行います。利用者の確認なしに書き込むこと、既存の予定を変更・削除することはありません。
  • Googleカレンダーの情報は、利用者ご本人に空き時間に合う求人をお知らせする機能と、利用者が依頼した予定の追加のためだけに使います。
  • Googleカレンダーの情報を、広告の配信・ターゲティングに使うことはありません。また、第三者へ販売・提供しません。
  • Googleカレンダーの情報を、AI（機械学習）モデルの学習には使いません。希望条件の解釈にAIのサービスを使う場合も、送るのは空き時間帯と利用者が設定した条件だけで、予定の件名・場所などは送りません。
  • 当社の従業員がGoogleカレンダーの情報を読むのは、利用者の同意を得た場合、セキュリティ上の調査が必要な場合、または法令に基づく場合に限ります。

The use and transfer to any other app of information received from Google APIs by Suzuki Medical Engineering LLC will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

当社がGoogle APIから受け取った情報の利用および他のアプリへの移転は、Limited Use（限定的使用）の要件を含む「Google API サービスのユーザーデータに関するポリシー」に従います。

4. 第三者への提供・委託

法令に基づく場合を除き、本人の同意なく個人情報を第三者に提供しません。本サービスの運営のため、次の事業者に処理を委託します。

  • Amazon Web Services（データの保管・処理。東京リージョン）
  • LINEヤフー株式会社（LINEでのお知らせの送信）
  • Anthropic（希望条件の解釈。送るのは上記3の範囲のみ）

5. 保管と安全管理

  • 情報は暗号化して保管し、通信も暗号化します。Googleへの接続に使う鍵は、専用の保管庫（AWS Secrets Manager）で管理します。
  • カレンダーの予定の内容は、空き時間の判定に使ったあと保存しません（判定結果の空き時間帯のみ保存します）。

6. 連携の解除と削除

  • Googleとの連携は、Googleアカウントの「サードパーティ製のアプリとサービス」からいつでも解除できます。
  • 退会・削除のご依頼をいただいた場合、30日以内に利用者の情報を削除します。

7. 開示・訂正・利用停止のご請求

ご本人の情報の開示・訂正・利用停止・削除のご請求は、下記の窓口までご連絡ください。ご本人であることを確認したうえで対応します。

8. 改定

本ポリシーを改定する場合は、このページでお知らせします。重要な変更は、本サービス内でもお知らせします。
